## 📋 Пошаговая инструкция

### Шаг 1: Загрузите код на GitHub

Если ещё не загрузили:

```bash
git init
git add .
git commit -m "Fix: add vite config and error handling"
git branch -M main
git remote add origin https://github.com/ВАШ_USERNAME/tv-na-stene.git
git push -u origin main
```

### Шаг 2: Создайте проект на Render

1. Перейдите на [render.com](https://render.com)
2. Войдите через GitHub
3. Нажмите **"New +"** → **"Static Site"**
4. Подключите ваш репозиторий `tv-na-stene`

### Шаг 3: Настройте деплой

Заполните поля:

| Поле | Значение |
|------|----------|
| **Name** | `tv-na-stene` |
| **Branch** | `main` |
| **Root Directory** | *(оставьте пустым)* |
| **Build Command** | `npm install && npm run build` |
| **Publish Directory** | `dist` |
| **Plan** | Free |

Нажмите **"Create Static Site"**

### Шаг 4: Дождитесь деплоя

- Сборка займёт 2-5 минут
- После успешного деплоя получите URL вида: `https://tv-na-stene.onrender.com`

## 🔗 Привязка домена tv-na-stene.ru

### 1. Добавьте домен в Render

1. В настройках сайта → **"Custom Domains"**
2. Нажмите **"Add Custom Domain"**
3. Введите `tv-na-stene.ru`
4. Скопируйте CNAME-запись

### 2. Настройте DNS у регистратора

Зайдите в панель управления доменом и добавьте записи:

**Для поддомена www:**
```
Тип: CNAME
Имя: www
Значение: tv-na-stene.onrender.com
```

**Для корневого домена:**
```
Тип: A
Имя: @
Значение: 76.76.21.21
```

> ⚠️ Точные IP Render указывает в панели - они могут меняться

### 3. Дождитесь обновления DNS

Обычно занимает 15 минут - 24 часа. HTTPS включится автоматически.

## 🐛 Если сайт не открывается

### Проверьте:

1. **В консоли браузера (F12)** - нет ли ошибок JavaScript
2. **В логах Render** - успешно ли прошла сборка
3. **Правильность путей** - в `dist/index.html` пути должны быть относительными (`./assets/...`)
4. **DNS записи** - правильно ли настроены у регистратора

### Частые проблемы:

**Белый экран:**
- Проверьте консоль браузера на ошибки
- Убедитесь что `base: './'` в `vite.config.ts`
- Проверьте что используется HashRouter (не BrowserRouter)

**404 при обновлении страницы:**
- Убедитесь что используется HashRouter
- Проверьте что в Render указан правильный Publish Directory (`dist`)

**CSS/JS не загружаются:**
- Проверьте пути в `dist/index.html` - должны быть `./assets/...`
- Убедитесь что `base: './'` в `vite.config.ts`
